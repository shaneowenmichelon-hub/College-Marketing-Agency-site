# Activation photo archive

Real activation photos that are kept on the site but deliberately **not** in the
homepage/carousel rotation. Nothing here is read automatically; reference a file
by path if you want it in a specific spot, or move it into `../hero/` to put it
back in the rotation.

Two reasons a photo lands here rather than in the rotation:

- **Product is the subject** rather than the activation (`stripz-product-lineup`,
  `stripz-rainbow-sampling`), so one sponsor's packaging would lead the site.
- **A regulated product's label is the focal point** (`stripz-neon-closeup`,
  `stripz-neon-pair`, `stripz-night-school-pair`) — the nicotine warning text
  reads clearly, and these are the first thing a prospective client sees.

`beatbox-green-room-alt` is just a near-duplicate of the green-room frame that is
in the rotation; either works, two in a row looks like a glitch.
