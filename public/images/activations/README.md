# Activation photo archive

Real activation photos that are kept on the site but deliberately **not** in the
homepage/carousel rotation — mostly close-up product shots. Nothing here is read
automatically; reference a file by path if you want it in a specific spot.

The main rotation lives in `../hero/` and leads with people at the activation
rather than product, so a close-up of a single sponsor's product never becomes
the first thing a visitor sees.
